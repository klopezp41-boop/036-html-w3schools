El atributo charset

Para mostrar una página correctamente, el navegador debe saber qué set de caracteres usar. Se especifica en la etiqueta meta (ya incluida en el head de este archivo):

<meta charset="UTF-8">

La especificación de HTML recomienda a los desarrolladores usar el set de caracteres UTF-8, ya que cubre casi todos los caracteres y símbolos del mundo.

El set de caracteres ASCII

ASCII fue el primer estándar de codificación de caracteres para la web. Definió 128 caracteres latinos distintos que se podían usar en internet:

  • Letras en inglés (a-z y A-Z)
  • Números (0-9)
  • Algunos caracteres especiales: ! $ + - ( ) @ < > . # ?

El set de caracteres ANSI

ANSI (Windows-1252) fue el primer set de caracteres de Windows:

  • Idéntico a ASCII en los primeros 127 caracteres
  • Caracteres especiales del 128 al 159
  • Idéntico a UTF-8 del 160 al 255
<meta charset="Windows-1252">

El set de caracteres ISO-8859-1

Fue el set de caracteres por defecto en HTML 4. Soportaba 256 caracteres:

  • Idéntico a ASCII en los primeros 127 caracteres
  • No usa los caracteres del 128 al 159
  • Idéntico a ANSI y UTF-8 del 160 al 255

Ejemplo en HTML 4

<meta http-equiv="Content-Type" content="text/html;charset=ISO-8859-1">

Ejemplo en HTML 5

<meta charset="ISO-8859-1">

El set de caracteres UTF-8

  • Idéntico a ASCII en los valores del 0 al 127
  • No usa los caracteres del 128 al 159
  • Idéntico a ANSI y 8859-1 del 160 al 255
  • Continúa desde el valor 256 hasta 10,000 caracteres
<meta charset="UTF-8">
