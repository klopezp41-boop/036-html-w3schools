Ruta absoluta (Absolute File Path)

Una ruta absoluta es la URL completa hacia un archivo.

Ruta relativa (Relative File Path)

Una ruta relativa apunta a un archivo en relación con la ubicación de la página actual. A continuación, algunos ejemplos de cómo se escribiría cada caso (no se muestran imágenes reales porque dependen de la estructura de carpetas del propio proyecto):

Ruta Descripción
<img src="imagen.jpg"> El archivo está en la misma carpeta que la página actual
<img src="images/imagen.jpg"> El archivo está en la carpeta "images" dentro de la carpeta actual
<img src="/images/imagen.jpg"> El archivo está en la carpeta "images" ubicada en la raíz del sitio
<img src="../imagen.jpg"> El archivo está en la carpeta un nivel arriba de la actual

Buena práctica

Se recomienda usar rutas relativas siempre que sea posible. Así, las páginas no dependen de la URL base y funcionan igual en local (localhost) como en un dominio público.
