Tipos de input disponibles

Existen muchos tipos de input en HTML: button, checkbox, color, date, datetime-local, email, file, hidden, image, month, number, password, radio, range, reset, search, submit, tel, text, time, url, week. Por defecto, si no se especifica, el tipo es "text".

Tipo texto






El ancho por defecto de un campo de texto es de 20 caracteres.

Tipo contraseña (password)






Los caracteres de un campo de contraseña se ocultan (se muestran como asteriscos o círculos).

Restricciones comunes para inputs

Atributo Descripción
checked Preselecciona un checkbox o radio al cargar la página
disabled Deshabilita el campo
max / min Valor máximo / mínimo permitido
maxlength Número máximo de caracteres
pattern Expresión regular para validar el valor
readonly El campo no se puede modificar
required El campo es obligatorio
size Ancho del campo en caracteres
step Intervalos numéricos permitidos
value Valor por defecto
