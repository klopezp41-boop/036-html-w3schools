¿Qué son los emojis?

Los emojis parecen imágenes, pero no lo son: son letras (caracteres) del set de caracteres UTF-8 (Unicode), que cubre casi todos los caracteres y símbolos del mundo.

El atributo charset

Para mostrar una página correctamente, el navegador debe saber el set de caracteres usado. Se especifica en la etiqueta meta (ya incluida en el head de este archivo):

<meta charset="UTF-8">

Si no se especifica, UTF-8 es el set de caracteres por defecto en HTML.

Caracteres UTF-8

Muchos caracteres UTF-8 no se pueden escribir directamente en el teclado, pero siempre se pueden mostrar usando números de entidad. Por ejemplo: A es 65, B es 66, C es 67.

Caracteres de emoji

Los emojis también son caracteres del alfabeto UTF-8. Por ejemplo: 😄 es 128516, 😍 es 128525, 💗 es 128151.

Emojis con tamaño personalizado

Como los emojis son caracteres, se pueden copiar, mostrar y ajustar de tamaño igual que cualquier otro carácter.
