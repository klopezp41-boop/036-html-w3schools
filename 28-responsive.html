Configurar el viewport

Para crear un sitio responsivo, se agrega la siguiente etiqueta meta en el head de todas las páginas (ya incluida en este archivo):

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Imágenes responsivas

Usando la propiedad width

Si el ancho se define en porcentaje, la imagen se agranda y se achica al cambiar el tamaño de la ventana. Nota: puede volverse más grande que su tamaño original.

Usando la propiedad max-width

Con max-width:100% la imagen se reduce si es necesario, pero nunca crece más allá de su tamaño original.
