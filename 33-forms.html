¿Qué es una URL?

Una URL es otra forma de decir "dirección web". Puede estar compuesta de palabras (como w3schools.com) o de una dirección IP (como 192.68.20.50). La mayoría de personas usan nombres porque son más fáciles de recordar que números.

Sintaxis de una URL

Una dirección web como https://www.w3schools.com/html/default.asp sigue esta estructura:

scheme://prefix.domain:port/path/filename
  • scheme - define el tipo de servicio de internet (el más común es http o https)
  • prefix - define un prefijo de dominio (por defecto en http es www)
  • domain - define el nombre de dominio (como w3schools.com)
  • port - define el número de puerto en el servidor (por defecto en http es 80)
  • path - define una ruta en el servidor (si se omite, se usa el directorio raíz)
  • filename - define el nombre del documento o recurso

Esquemas de URL comunes

Esquema Significado Se usa para
http HyperText Transfer Protocol Páginas web comunes. No encriptado
https Secure HyperText Transfer Protocol Páginas web seguras. Encriptado
ftp File Transfer Protocol Descargar o subir archivos
file - Un archivo en tu computadora

Codificación de URL (URL Encoding)

Las URLs solo se pueden enviar por internet usando el set de caracteres ASCII. Si una URL contiene caracteres fuera de ese set, debe convertirse.

La codificación de URL reemplaza los caracteres que no son ASCII con un símbolo "%" seguido de dígitos hexadecimales. Las URLs no pueden contener espacios: normalmente se reemplazan con un signo "+" o con "%20".
