El elemento form

El elemento <form> es un contenedor para distintos tipos de elementos de entrada: campos de texto, casillas de verificación, botones de opción, botones de envío, etc.

El elemento input

Es el elemento de formulario más usado. Puede mostrarse de muchas formas según su atributo type:

Tipo Descripción
<input type="text"> Muestra un campo de texto de una línea
<input type="radio"> Muestra un botón de opción (para elegir una entre varias opciones)
<input type="checkbox"> Muestra una casilla de verificación (para elegir cero o más opciones)
<input type="submit"> Muestra un botón para enviar el formulario
<input type="button"> Muestra un botón normal

Campos de texto




El formulario en sí no se ve visualmente, y el ancho por defecto de un campo de texto es de 20 caracteres.

El elemento label

La etiqueta <label> define una etiqueta para varios elementos de formulario. Es útil para lectores de pantalla y también facilita hacer clic en casillas o botones de opción pequeños, ya que hacer clic en el texto del label activa el input asociado. El atributo for del label debe coincidir con el id del input para vincularlos.

El botón de envío (submit)

El elemento <input type="submit"> define un botón para enviar los datos del formulario a un manejador de formulario, especificado en el atributo action.






El atributo name en input

Cada campo de entrada debe tener un atributo name para que su valor se envíe. Si se omite, el valor del campo no se enviará.
