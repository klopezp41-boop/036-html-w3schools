El atributo action

Define la acción a realizar cuando se envía el formulario. Normalmente los datos se envían a un archivo del servidor. Si se omite, la acción se envía a la página actual.

El atributo method

Notas sobre GET

  • Agrega los datos del formulario a la URL, en pares nombre/valor
  • Nunca se debe usar para enviar datos sensibles (quedan visibles en la URL)
  • La URL tiene un límite de longitud (2048 caracteres)
  • Útil cuando se quiere poder guardar el resultado en favoritos

Notas sobre POST

  • Envía los datos dentro del cuerpo de la solicitud HTTP (no se ven en la URL)
  • No tiene límite de tamaño, sirve para grandes cantidades de datos
  • No se puede guardar en favoritos el resultado de un envío con POST

Siempre se recomienda usar POST cuando el formulario contiene información sensible o personal.
