El elemento title

El título se define en el <head> y se muestra en la pestaña del navegador, en favoritos y en resultados de buscadores. En este archivo, el título es "El Elemento Head en HTML" (revisa la pestaña de tu navegador).

El elemento style

Permite definir estilos CSS directamente en la página. En este archivo se usó para poner en rojo el siguiente encabezado:

Este es un encabezado en rojo

El elemento link

Se usa para enlazar hojas de estilo externas. Así se vería en el head:

<link rel="stylesheet" href="mystyle.css">

El elemento meta

Define información sobre la página que no se muestra visualmente, pero que usan navegadores y buscadores. En este archivo ya se incluyeron en el head: charset (UTF-8), descripción, palabras clave, autor y viewport.

La etiqueta viewport

Controla cómo se ve la página en distintos dispositivos. Se incluyó en el head de este archivo:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

El elemento base

Define la URL base y/o el destino por defecto para todos los enlaces relativos de la página. Solo puede haber un <base> por documento. No se agregó de forma funcional en este archivo porque afectaría todos los demás enlaces de la página, pero así se vería:

<base href="https://www.w3schools.com/" target="_blank">
