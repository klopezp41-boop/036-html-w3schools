Elementos de layout (semánticos)

HTML5 tiene elementos semánticos que definen las distintas partes de una página web:

<header>
<nav>
<section>
<article>
<aside>
<footer>
  • <header> - Define un encabezado para un documento o sección
  • <nav> - Define un conjunto de enlaces de navegación
  • <section> - Define una sección dentro de un documento
  • <article> - Define contenido independiente y autocontenido
  • <aside> - Define contenido aparte del contenido principal (como una barra lateral)
  • <footer> - Define un pie de página para un documento o sección
  • <details> - Define detalles adicionales que el usuario puede abrir y cerrar
  • <summary> - Define un encabezado para el elemento <details>

Técnicas de layout

Existen varias formas de crear diseños de múltiples columnas: frameworks de CSS, la propiedad float, flexbox y grid.

Layout con float

Se puede crear un diseño completo usando la propiedad CSS float. Es fácil de aprender, aunque tiene la desventaja de que los elementos flotantes quedan ligados al flujo del documento.
