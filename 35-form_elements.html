Elementos que puede contener un formulario

El elemento <form> puede contener elementos como: <input>, <label>, <select>, <textarea>, <button>, <fieldset>, <legend>, <datalist>, <output>, <option> y <optgroup>.

El elemento input




El elemento label

Define una etiqueta para varios elementos de formulario. Es útil para lectores de pantalla y facilita hacer clic en elementos pequeños como radios o checkboxes. El atributo for debe coincidir con el id del input para vincularlos.

El elemento select (lista desplegable)

El elemento textarea



El atributo rows especifica el número de líneas visibles, y cols el ancho visible del área de texto.

El elemento button

Nota: siempre se debe especificar el atributo type del botón, ya que distintos navegadores pueden usar tipos por defecto diferentes.

Los elementos fieldset y legend

El elemento <fieldset> se usa para agrupar datos relacionados en un formulario, y <legend> define un título para ese grupo.

El elemento datalist

Especifica una lista de opciones predefinidas para un input. El usuario ve una lista desplegable de sugerencias mientras escribe. El atributo list del input debe coincidir con el id del datalist.

El elemento output
