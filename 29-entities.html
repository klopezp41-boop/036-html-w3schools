¿Qué son las entidades HTML?

Algunos caracteres están reservados en HTML. Si usas los signos menor que (<) o mayor que (>) en tu texto, el navegador podría confundirlos con etiquetas.

Se pueden usar nombres de entidad o números de entidad para mostrar estos caracteres reservados: &entity_name; o &#entity_number;.

Ejemplo: para mostrar el signo menor que (<) se escribe &lt; o &#60;.

Espacio de no separación (non-breaking space)

Una entidad muy usada es &nbsp;, un espacio que no se separa en una nueva línea. Es útil para mantener juntas dos palabras:

10 km/h

10 PM

También se usa para evitar que el navegador elimine espacios extra en el texto.

Marcas diacríticas (Combining Diacritical Marks)

Una marca diacrítica es un "glifo" que se agrega a una letra, como el grave o el agudo, también llamados acentos. Se combinan con letras para producir un carácter que no está en el set de caracteres de la página:

̀ a a&#768; à
́ a a&#769; á
̂ a a&#770; â
̃ a a&#771; ã
̀ O O&#768; Ò
́ O O&#769; Ó
̂ O O&#770; Ô
̃ O O&#771; Õ
